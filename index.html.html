☁️ المزامنة السحابية

غير مفعّلة

المزامنة السحابية تتيح استخدام نفس الحساب على جميع أجهزتك (متحانات، آيباد، جوال) مع مزامنة تلقائية لكل بياناتك.

  1. أنشئ حساباً مجانياً على console.firebase.google.com وابدأ مشروعاً جديداً.
  2. أضف تطبيق ويب (رمز </>) وانسخ إعدادات Firebase.
  3. فعّل تسجيل الدخول: Build → Authentication → Sign-in method → Email/Password.
  4. أنشئ قاعدة بيانات: Build → Firestore Database → إنشاء.
  5. الصق الإعدادات المنسوخة في الحقل أدناه.
